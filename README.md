# Визуализатор зависимостей Maven

## Этап 3

Программа строит граф зависимостей нерекурсивным DFS,
учитывает максимальную глубину и обнаруживает циклы.
Используется только стандартная библиотека Python 3.

## Параметры

| Параметр | Назначение |
| --- | --- |
| `-p` | Имя пакета: groupId:artifactId или A, B, C для test |
| `-r` | URL репозитория или локальный путь |
| `-m` | Режим: url, path, test |
| `-v` | Версия; для test не используется |
| `-t` | y/n; ASCII-дерево относится к этапу 5 |
| `-d` | Максимальная глубина, начиная с 0 |

## Запуск

Из корня проекта:

```sh
python3 -m src.main -p A -r tests/pom.xml -m test -v 1 -t n -d 2
```

Пример вывода:

```text
Граф зависимостей в пределах заданной глубины:
A -> B, C
B -> D
C -> D
D -> []
Циклов нет
```

При глубине 0 выводится только исходный пакет,
при глубине 1 — исходный пакет и прямые зависимости.
`[]` означает отсутствие раскрытых зависимостей в заданной глубине.

## Демонстрация

```sh
python3 -m src.main -p A -r tests/pom.xml -m test -v 1 -t n -d 1
python3 -m src.main -p E -r tests/pom.xml -m test -v 1 -t n -d 3
python3 -m src.main -p H -r tests/pom.xml -m test -v 1 -t n -d 3
python3 -m src.main -p I -r tests/pom.xml -m test -v 1 -t n -d 1
```

A — ограничение глубины; E — цикл; H — нет зависимостей;
I — зависимость от самого себя. Циклы проверяются только
в построенной части графа.

`tests/pom.xml` — собственный тестовый XML с корнем repository,
а не стандартный Maven POM. Режимы url/path читают настоящие POM.
Для path передается папка Maven-репозитория или исходный POM;
в последнем случае POM зависимостей ищутся по Maven-структуре
относительно его папки.

Поддержаны конкретные версии и простые локальные properties.
Внешние parent POM, dependencyManagement, BOM, фильтрация scope,
exclusions, диапазоны версий и разрешение конфликтов не реализованы.
Неопределенная версия зависимости приводит к ошибке.
